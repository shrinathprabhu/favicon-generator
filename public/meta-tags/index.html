Local dev servers usually block cross-origin requests. Any of these will work:

  1. Drag Send to Meta Tags to your bookmarks bar, open your local page, and click the bookmark. It also picks up tags your app adds with JavaScript.
  2. Open the page source (view-source:), copy everything, and use .
  3. Clone the repo and run npm run gui. The local version fetches localhost pages directly.
